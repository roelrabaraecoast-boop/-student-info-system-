# Student Information System

A simple Student Information System developed using Python. This project helps organize and manage student records.

## Features

- Add student records
- View student information
- Update student records
- Delete student records
- Store student data using JSON

## Technologies Used

- Python 3
- JSON
- Visual Studio Code

## Project Structure

```text
student-info-system/
├── src/
│   ├── main.py
│   ├── models/
│   │   └── student.py
│   └── services/
│       └── student_service.py
├── data/
│   └── students.json
├── requirements.txt
├── .gitignore
└── README.md
```

## Requirements

- Python 3.x
- Visual Studio Code (recommended)

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal in the project directory.
4. Run the application:

```bash
python src/main.py
```
